# Seattle Evergreen Clean – Instant Quote Calculator

Plain HTML/CSS/JS, no build step. Deployed on Netlify as its own project with `evergreen-quote` as the base folder.

## Change prices
Edit `pricing.js`. Every price there is a SAMPLE until you replace it. When your real prices are in, set `PRICES_CONFIRMED: true` and the "Sample prices" notice disappears.

## Requests
The "Request this cleaning" form uses Netlify Forms (form name `quote-request`). Submissions show under Forms in the Netlify project.
